🛡️ สิทธิ์เฉพาะผู้ดูแล (Admin Only)

จำกัดการมองเห็นและการเข้าใช้งานเฉพาะบัญชีระดับ admin เท่านั้น เจ้าหน้าที่ทั่วไปหรือประชาชนจะไม่เห็นเมนูนี้

🏢 ขอบเขตระดับหน่วยงาน (Scoped)

ผู้ดูแลสามารถปลดล็อกได้เฉพาะเจ้าหน้าที่ในหน่วยงานของตนเองเท่านั้น ป้องกันการแทรกแซงข้ามหน่วยงาน

📋 บันทึกประวัติ (Audit Logs)

ทุกการปลดล็อกจะบังคับเลือกเหตุผล 5 ประการ และบันทึกชื่อผู้ดำเนินการ เวลา และค่าเคาน์เตอร์ย้อนหลัง

⚡ ปลดล็อกทันที (No Manual DB)

รีเซ็ตค่าเคาน์เตอร์เป็น 0 ผ่านหน้าบ้านทันที ลดภาระของทีม Dev / DevOps ไม่ต้องเข้าฐานข้อมูลโดยตรง
